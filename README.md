Entry for make.fun's "One Emoji, One Dream Vacation" bounty ($2, one winner): a Node program with no dependencies that writes exactly one emoji — 🏝️, a desert island — to /output/entry.txt. The island is the whole dream vacation as a wordless postcard: a faraway place with palm, sand and sea in a single glyph, picked because it plainly names a dream vacation at a glance.

## Run it

```sh
node main.ts
```
